# Keep the public website separate from operational platforms

The observed GlobalCluster website sends visitors to separate payroll and financial-statement applications. The redesign brief therefore scopes Next.js to public solution discovery, resources, contact and platform access, preserving the published application destinations instead of migrating authentication or business data. This keeps application ownership and availability independent, at the cost of a transition to an external interface when visitors access a platform; this is a recommended scope interpretation, not a separately confirmed migration decision.
